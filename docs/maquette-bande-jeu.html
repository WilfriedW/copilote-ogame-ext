La bande du copilote dans la page du jeu

Retenue le 2026-11-24 : la proposition C, groupée par état avec la ligne de résumé. Les autres restent ici pour mémoire.

Ce que l'extension pose dans la page d'OGame — pas le panneau latéral. L'état d'aujourd'hui, puis trois façons d'afficher la même chose. Les couleurs sont les jetons de content.js : la dernière bande montre les quatre habillages tels qu'ils tombent vraiment depuis le réglage du panneau.

Le tour de ce qui est visible dans la page du jeu

Bande, zone « ici »
Jusqu'à 4 lignes : ce que le plan veut lancer sur cette page. Chaque ligne dit quoi · où · quand, c'est un lien, et le pourquoi est dans l'infobulle. Grisée quand le stock ne paie pas encore.
Bande, zone « tour »
Une pastille par planète qui connaît la tuile ouverte : nom · niveau → niveau+1 · état. L'état est soit file Xh, soit manque N ressource · payable dans X. Pleine = lançable, cerclée = ici, atténuée = bloquée.
Pastille sur la tuile
Le niveau visé, en haut à droite de la case, plus un liseré autour de la case conseillée. Bleue = le plan, ambre = ta priorité, ambre cerclée = ta demande pas encore reprise.
Encadré d'attente
Sur la page d'une action qui attend : ce qui manque, quand ce sera payé, et un bouton vers la bonne page.
Heures du jeu
Soulignées en pointillé quand le copilote les a relues pour les dire dans ton fuseau.
Colonne de droite
Seulement avec « peau complète » : les mêmes lignes qu'Aujourd'hui, en cartes.

B

Une ligne par planète, en colonnes

Les pastilles deviennent un tableau compact : nom, saut, état, lien. L'œil descend une colonne au lieu de traverser sept pastilles. Coûte de la hauteur, la gagne en lisibilité dès cinq planètes.

Groupée par état, avec le compte
